# Identidad de Brote

Todos los elementos de la marca Brote, agencia digital para el sector agrícola de México.
La versión navegable de esta guía vive en el sistema de diseño de Brote (claude.ai).

| Carpeta | Contenido |
| --- | --- |
| `guia/` | Lineamientos de marca, estrategia, voz y mensajes, servicios |
| `logos/png/` | Wordmark en petróleo (principal), blanco y verde; ícono; imagen de perfil para redes |
| `logos/favicon/` | Ícono en 16, 32, 48, 180, 192 y 512 px |
| `color/` | Paleta (`tokens.json`, `paleta.css`) y tabla de contraste |
| `tipografia/` | Fuentes, licencias y escala tipográfica |
| `iconos/` | Íconos de los 6 servicios (SVG, trazo en verde brote) |
| `patrones/` | Ondas, diagonales y líneas decorativas (SVG) |
| `hoja-de-marca.html` | Resumen visual de una página para compartir |
