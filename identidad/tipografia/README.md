# Tipografía

| Rol | Fuente | Pesos | Dónde |

| Citas y testimonios | Lora itálica | 400 | Solo citas |

Ambas son gratuitas (licencia SIL Open Font License) y están en Google Fonts:
- https://fonts.google.com/specimen/Urbanist
- https://fonts.google.com/specimen/Lora

En el sitio se cargan desde el propio proyecto con `@fontsource/urbanist` y `@fontsource/lora`.
